# Deep Reef 1.0.24 — stone border and rounded edges

The downward side/front finger extensions are removed. A small border of separate, irregular closed stone meshes surrounds the full foot. Neutral stone grain and faceted surface lighting distinguish these fragments from a continuous rim. Static view-normal shading darkens the tissue perimeter, with a strong factor on the complete pedal column and a gentler factor on the fingers. Existing 80% tentacle opacity and crown movement are retained. Blender contains the same stone meshes and edge-shade attributes.

Validation: 48 Python package, geometry, material and release checks; a targeted native collision check covering physical and interpolated fish poses; matching source/ZIP release checks; browser screenshot with all assets loaded and no page errors. Geometry checks verify that dangling finger extensions are absent, the full column remains closed, and the low stone border is closed and correctly ordered. No fish movement code changed. The screenshot is a desktop development preview; actual Roku hardware was not measured.
