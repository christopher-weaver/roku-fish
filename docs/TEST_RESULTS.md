# Deep Reef 1.0.22 — neutral rock and base shading

The narrow lip uses a separate neutral mineral-grain material instead of the platform's coloured coral projection. The lower pedal-column tissue has a gradual static shadow, and the rock directly beneath the foot receives a soft contact shadow. These effects are baked into the object materials; the full anemone geometry, moving fingers and 80% tentacle opacity remain unchanged. The same maps are included in the editable Blender scene.

Validation: 48 Python package/geometry/material/release checks, a targeted native collision check covering physical and interpolated fish poses, matching source/ZIP release checks, and a browser screenshot with all assets loaded and no page errors. No fish movement code changed. The screenshot is from the desktop development preview; actual Roku hardware was not measured.
